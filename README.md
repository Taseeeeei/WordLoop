# WordLoop Web版（PWA）― 公開とインストールの手順

このフォルダの中身をインターネット上に置くだけで、誰でもスマホやパソコンにインストールして使えます。
**一度開けば、その後は完全にオフラインで動きます**（機内モードでもOK）。

```
├─ index.html            アプリの画面
├─ app.js                アプリの動き（プログラム）
├─ sw.js                 オフラインで動かすための仕組み
├─ manifest.webmanifest  アプリ名・アイコンなどの情報
├─ icon*.png / favicon   アイコン
├─ fonts/                文字のデータ（英数字用。日本語はスマホ内蔵の文字を使用）
└─ privacy-policy.html   プライバシーポリシー
```

---

## 1. 公開する前に

`privacy-policy.html` をメモ帳で開き、**【ここに連絡先メールアドレスを記入】** を書き換えて保存してください。

---

## 2. GitHub Pages で無料公開する

1. https://github.com でアカウントを作る（無料）
2. 右上の「＋」→ **New repository**
   - Repository name：`wordloop`
   - **Public** を選んで **Create repository**
3. 「**uploading an existing file**」をクリック
4. このフォルダの **中身をすべて**（`fonts` フォルダごと）ドラッグ＆ドロップ → **Commit changes**
   - ⚠️ フォルダ「wordloop-pwa」そのものではなく、その **中身** を入れてください
5. リポジトリの **Settings → Pages**
   - Source：**Deploy from a branch**
   - Branch：**main** ／ **/(root)** → **Save**
6. 1〜2分待つと、次の URL で開けるようになります
   - アプリ：`https://あなたのユーザー名.github.io/wordloop/`
   - プライバシーポリシー：`https://あなたのユーザー名.github.io/wordloop/privacy-policy.html`

この URL を友だちに送れば、誰でも使えます。

---

## 3. スマホにインストールする

一度だけ、**インターネットにつながった状態** で URL を開いてください。

- **Android（Chrome）**：画面下に出る「インストール」、またはメニュー（︙）→「**アプリをインストール**」／「ホーム画面に追加」
- **iPhone（Safari）**：下の共有ボタン（□↑）→「**ホーム画面に追加**」
- **パソコン（Chrome / Edge）**：アドレスバー右端のインストールボタン

ホーム画面のアイコンから開くと、アプリと同じように全画面で動きます。

---

## 4. オフラインで使えるもの・使えないもの

| 機能 | オフライン |
|---|---|
| 単語帳・ファイル・単語の追加や編集 | ✅ |
| 写真の追加・表示 | ✅ |
| カード・4択・スペルテスト・赤シート | ✅ |
| 設定（色調・音量・効果音） | ✅ |
| バックアップの書き出し・読み込み | ✅ |
| 単語の読み上げ | △ 端末に音声データがあれば ✅（ふつうは入っています） |
| 学習リマインダー | △ **アプリを開いている間だけ** お知らせ（Web版の仕組み上、閉じているときの通知はできません） |

---

## 5. データについて（大切）

- 単語帳や写真は **その端末の中だけ** に保存されます（サーバーには送られません）
- 端末ごとに別々のデータです。機種変更のときは「設定 → バックアップ → 書き出す」で保存し、新しい端末で「読み込む」
- **iPhone は必ず「ホーム画面に追加」してから使ってください。** Safari のタブのまま使うと、しばらく開かないうちにデータが消えることがあります
- ブラウザの「閲覧データを削除」をすると消えることがあります。ときどきバックアップを書き出しておくと安心です

---

## 6. アプリを更新するとき

1. `index.html` などを書き換える
2. **`sw.js` の `VERSION` の数字を1つ増やす**（例：`'wordloop-v4'` → `'wordloop-v5'`）
   - これを忘れると、使っている人のスマホに新しい版が届きません
3. GitHub の同じ場所にファイルをアップロードし直す（上書き）

使っている人がインターネットにつながった状態でアプリを開くと、新しい版がダウンロードされ、**次に開いたとき** に反映されます。

---

## 文字データ（フォント）について

`fonts/` には Inter フォント（SIL Open Font License 1.1）を英数字だけに絞って同梱しています。
ライセンス上、`fonts/OFL.txt` は消さずに一緒に置いておいてください。

---

## セキュリティについて

- 外部のプログラムや外部サーバーとの通信は一切ありません
- `index.html` に、許可したファイル以外を読み込ませない設定（Content-Security-Policy）を入れています
- 他のサイトの中に埋め込まれた場合は動かないようにしています（なりすまし対策）
- 読み込むバックアップファイルは中身を検査し、不正な値は自動で取り除きます
- **GitHub Pages の注意**：同じ GitHub アカウントで公開したサイトどうしは、ブラウザ上で保存領域を共有します。
  このアカウントでは、他人が作ったページや出どころのわからないページを公開しないでください
  （気になる場合は、WordLoop 専用の GitHub アカウントを作るのがおすすめです）
